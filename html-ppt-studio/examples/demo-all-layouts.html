LangGraph

LangGraph 执行流程图

通过节点、边和条件路由描述 Agent 的执行逻辑
START
agent 节点调用模型，生成回复
tools_condition判断是否需要工具调用
工具调用执行工具，获取结果
最终回答生成最终结果
tools 节点将工具结果写入 State
END
1从 START 开始，进入 agent 节点
2agent 根据当前 State 构造输入并调用 LLM
3根据模型返回，判断是否有工具调用
4结果保存到 State 中
5无工具调用时直接结束
6工具执行完成后，返回 agent 节点进行下一轮模型调用

核心代码（简化示例）

from langgraph.graph import StateGraph
b = StateGraph(AgentState)
b.add_node("agent", call_model)
b.add_node("tools", ToolNode(tools))
b.add_edge(START, "agent")
b.add_conditional_edges("agent",
  tools_condition, {"tools": "tools"})
b.add_edge("tools", "agent")
graph = b.compile()

节点说明

agent 节点调用模型，生成回复
tools_condition判断是否需要工具调用
工具调用执行工具，获取结果
最终回答生成最终结果

核心理解

  • 循环由图的回边表达
  • State 保存执行过程中的数据
  • 条件路由决定下一步走向
